**Evidence elements:** original data, an expert quote (named, credentialed), citations to

**Comparisons:** which alternatives readers will weigh, and a fair comparison.

**Structure:** question-style headings; self-contained sections that name the subject; a table
for comparable facts; a visible "Last updated" date.

**Technical:** server-rendered; canonical URL; included in the sitemap with an accurate
`lastmod`; schema type, if any, matching the visible content.

**Distribution:** which third-party sources (reviews, publications, communities) should
reflect these facts, and who owns updating them.

**Measurement:** prompts in the prompt set that this page should influence.
